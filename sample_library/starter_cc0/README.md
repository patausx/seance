# seance CC0 starter samples

A compact starter library selected from the public-domain **Stargate Sample Pack**:

- upstream: https://github.com/stargatedaw/stargate-sample-pack
- upstream branch: `main`
- downloaded/checked: 2026-07-10
- license: CC0 1.0 Universal; see `CC0-1.0.txt`
- local conversion: mono, 32 kHz, signed PCM16 WAV using FFmpeg

These converted files are ready for seance. In the release ZIP, extract the included `3ds/` directory to the root of the SD card. From this source directory, copy the contents of `wav/` to:

```text
sdmc:/3ds/seance/samples/
```

Then open a PLAY, GRAN, or REC unit, tap its `Sxx` field, and select a filename.
