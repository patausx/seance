# dependency sources

this directory retains the original source archives, package recipes and
checksum inventory for dependencies used by the application. these are
redistribution/build inputs, not generated application output.

see [dependency-sources.md](dependency-sources.md) for versions, original source
locations, notices and the remaining linked-runtime review. keep the original
notices and source access alongside binary downloads. the application license
and dependency terms remain separate.

local publication drafts, store-submission notes and media instructions are not
part of the source repository. release packaging commands live in
[scripts/](../scripts/README.md).
